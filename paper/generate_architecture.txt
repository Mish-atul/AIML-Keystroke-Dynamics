DETAILED COMPONENT SPECIFICATIONS:
================================================================================

1. INPUT REPRESENTATION:
   - Keystroke timing matrix: (batch_size, 11 keys, 3 features)
   - 11 keys: Each character in ".tie5Roanl"
   - 3 features per key:
     * H (Hold time): Key press duration
     * DD (Down-Down): Time between consecutive key presses
     * UD (Up-Down): Time from key release to next key press
   - Total: 31 raw timing features (11×3 - 2 boundary conditions)

2. ENCODER ARCHITECTURE:
   Layer 1: Conv1D(in=3, out=64, kernel=3, padding=1)
            → BatchNorm1D(64) → ReLU → MaxPool1D(2)
   Layer 2: Conv1D(in=64, out=128, kernel=3, padding=1)
            → BatchNorm1D(128) → ReLU → MaxPool1D(2)
   Layer 3: Conv1D(in=128, out=256, kernel=3, padding=1)
            → BatchNorm1D(256) → ReLU → GlobalAvgPool1D
   Layer 4: Linear(256, 128) → L2-Normalize
   
   Total Parameters: ~158,000
   Output: 128-dimensional unit-norm embedding

3. SUPERVISED CONTRASTIVE LOSS (SupCon):
   L = -1/|P(i)| × Σ_{p∈P(i)} log[ exp(z_i·z_p/τ) / Σ_{a∈A(i)} exp(z_i·z_a/τ) ]
   
   Where:
   - P(i): Set of positive samples (same user as anchor i)
   - A(i): All samples except anchor i
   - τ = 0.07 (temperature parameter)
   - z: L2-normalized embeddings

4. ADAPTER ARCHITECTURE:
   Input: 128-d frozen embedding
   Layer 1: Linear(128, 64) → ReLU → Dropout(0.2)
   Layer 2: Linear(64, 128)
   Output: 128-d adapted embedding
   
   Total Parameters: ~16,576 per user
   Note: No residual connection (best performance)

5. TRIPLET LOSS:
   L = max(0, ||f(a) - f(p)||² - ||f(a) - f(n)||² + margin)
   
   Where:
   - a: Anchor (user's enrollment sample)
   - p: Positive (same user, augmented)
   - n: Negative (different user sample)
   - margin = 0.3

\caption{Overview of the proposed two-stage framework for keystroke dynamics 
authentication. \textbf{Stage 1}: A 1D-CNN encoder ($\sim$158K parameters) is 
pretrained on 36 users using Supervised Contrastive Loss, learning to map 
keystroke timing sequences to a discriminative 128-dimensional embedding space. 
\textbf{Stage 2}: For each new user, a lightweight adapter ($\sim$16.5K parameters) 
is trained on $k$ enrollment samples with Triplet Loss while the encoder remains 
frozen. During verification, the cosine similarity between the query embedding 
and stored user centroid determines authentication success.}
